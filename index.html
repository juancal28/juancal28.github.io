01

NBA Totals Bot — Polymarket Trading in Rust

A Rust bot that trades NBA game-total over/under markets on Polymarket. It follows the first quarter through SportRadar, fits a Poisson rate to per-minute scoring, and uses a likelihood-ratio test against the opening minutes of the second quarter to decide whether that rate can be trusted. A bootstrap gives a confidence interval for the final total, and the pace projection is blended with the market line using a least-squares fit over 638 backtested games. When the edge clears its threshold, the order is sized with depth-aware fractional Kelly and submitted fill-or-kill to the order book. A backtester and a paper-trading mode drive the same engine and record the blended and pace-only models side by side.

  • Rust

  • Poisson MLE

02

ScreenInhibitor — Screen Time Limits for iOS

An iOS app that puts a hard budget on distracting apps. Each limit gives a group of apps one shared allowance, then blocks them all for a set period, enforced through Apple's Screen Time frameworks by a DeviceActivity monitor extension. Breaks lift every limit for a few minutes, once per break per day, and edits to them only take effect at the next midnight, so changing the settings is never a way to get more time today. While an app is blocked, a Messages tab keeps direct messages reachable in a web view with the Reels feed stripped out in three layers: WebKit content rules, a native navigation policy, and injected JavaScript. A reel shared in a DM still plays, but is locked so that swiping cannot reach another one. The policy logic is written as pure functions and covered by XCTest.

03

Japanese Conjugation Practice — Drills from Your Own Anki Decks

A conjugation trainer that drills the verbs and adjectives from your own Anki decks, such as a single textbook chapter, instead of a fixed word list. Importing an .apkg file parses the deck, looks up each card's part of speech in JMdict, and has Claude review every card to normalize conjugated entries and skip nouns and phrases; a review table then previews live conjugations so mistakes stand out before the deck is saved. Answer keys come from a deterministic conjugation engine, not from the model, and golden tests check it against Steven Kraft's practice page, which the quiz is modeled on. A reference page lists the rule behind every accepted answer, and a test fails if any answer has no rule.

04

Quant News-RAG Trading System

An autonomous paper-trading system that reads financial news, proposes changes to its own strategy, and trades $100K of simulated capital. News from RSS feeds is deduplicated, embedded into Qdrant, and scored for sentiment with FinBERT. A Claude-backed RAG agent proposes minimal, citation-backed strategy adjustments, which must pass a validator (approved tickers, position limits, change scope) and a quality score built from evidence strength, recency, sentiment consensus, and coverage before they reach approval, which can be manual, time-gated, or fully autonomous. Backtests over a one-year in-sample and 90-day out-of-sample window stay available on demand. The backtest engine, paper broker, and risk checks are compiled to native C++ via pybind11, a 2% daily-loss circuit breaker halts trading, and a quant CLI with a live dashboard runs the whole system on Railway.

Homely — Full-Stack Home Services Marketplace

A dual-sided marketplace connecting homeowners with trade professionals, with a consumer app and a separate Pro Portal for jobs, scheduling, earnings, and messages. Homeowners browse verified subcontractors by specialty and location, collect competing bids, book and track work, and browse land listings. An AI assistant built on the Anthropic Claude API streams its answers, retrieves from a RAG pipeline over ingested documents, and acts through an MCP tool server, with LLM-as-judge tests covering the tool loop. Authentication uses JWT with role-based access and email verification for logins from a new device, and secret scanning runs in a pre-commit hook and in CI. Ships as an installable PWA with Capacitor shells for iOS and Android.

06

Deterministic World Generation — Java Dungeon Explorer

A 2D tile-based dungeon explorer in Java where any seed deterministically generates the same world. The 60×45 grid is partitioned into zones, rooms of random size are placed with collision detection, and my own implementation of Prim's algorithm connects them with a minimum spanning tree of L-shaped hallways. A fog-of-war mode computes line of sight with Bresenham's line algorithm, and saving stores only the seed and the player's inputs, then replays them on load.

08

Tower Stacking Game

A puzzle game in the spirit of the Towers of Hanoi: rearrange colored blocks across towers to match a target configuration in as few moves as possible. Puzzles are generated at random with 5–12 blocks, and a breadth-first search over game states finds the optimal move count, which the game can replay as an animated solution. Includes a move counter, a reset for the same puzzle, and a new-game button, and it runs in the browser.

In progress

“How Does the Optimizer Shape Generalization in In-Context Regression?”

Arihant Kaul, Phil Liu, Nayan Ramakrishnan, Juan Calderon

Transformers pretrained on a finite pool of linear-regression tasks show a task-diversity threshold: below it they memorize the pool, and above it they learn ridge regression and generalize to unseen tasks. That threshold has been measured almost only under Adam, so we ask whether the optimizer (SGD, AdamW, or Muon) moves it, and whether the shift can be predicted from how fast each optimizer learns regression versus how fast it memorizes. I built the experiment runner: a PyTorch port of the Raventós et al. recipe in which one seed fixes the task pool, the initial weights, and the data stream across a 54-run grid of pool sizes, optimizers, and batch sizes, with resumable runs and one worker per GPU. In a preliminary single-seed sweep at 20,000 steps per run, the threshold fell near 29.7 tasks under AdamW and 210.8 under Muon. The full grid is 500,000 steps per run across four seeds.
